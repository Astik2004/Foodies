## Root .gitignore (`.gitignore`)

Covers project-wide patterns for entire monorepo:

### Categories:

**IDE & Editors**
- `.idea/` - IntelliJ IDEA settings
- `.vscode/` - VS Code settings
- `.project`, `.classpath` - Eclipse
- `*.swp`, `*.swo` - Vim temporary files

**Environment & Secrets** ⚠️
- `.env` - Development environment variables
- `.env.local` - Local overrides
- `*.pem`, `*.key`, `*.crt` - SSL/TLS certificates
- `secrets/` - Directory for sensitive data

**Build Output**
- `target/` - Maven build directory
- `dist/` - Frontend build directory
- `build/`, `out/` - Alternative build directories
- `*.jar`, `*.war` - Compiled archives

**Logs**
- `logs/` - Application log files
- `*.log`, `*.log.*` - All log files
- npm/yarn debug logs

**Dependencies**
- `node_modules/` - Node packages
- `package-lock.json`, `yarn.lock` - Lock files
- `.gradle/`, `.m2/` - Gradle/Maven caches

**Test Coverage**
- `coverage/` - Test coverage reports
- `jacoco-report/` - JaCoCo coverage
- `jest-coverage/` - Jest coverage

**Database & Cache**
- `*.db`, `*.sqlite*` - SQLite databases
- `dump.rdb`, `appendonly.aof` - Redis persistence files

**OS Files**
- `.DS_Store` - macOS folder metadata
- `Thumbs.db` - Windows thumbnail cache
- Desktop.ini, .Trashes - OS-specific files

**Upload Directories**
- `upload/*` - User uploads (with `.gitkeep` to preserve directory)
- `public/uploads/*` - Public upload directory

✅ **Test Coverage** - All coverage report formats ignored

## What Gets Committed

✅ Source code (`.java`, `.jsx`, `.css`)  
✅ Configuration files (`pom.xml`, `package.json`, `application.properties`)  
✅ Docker files (`Dockerfile`, `docker-compose.yml`)  
✅ Documentation (`.md` files)  
✅ `.mvn/wrapper/` - Maven wrapper (reproducible builds)  
✅ `.vscode/` settings with exclusions for sensitive data  
✅ `.gitkeep` files in `upload/` directories  

---

## What Gets Ignored

❌ Dependencies (`node_modules/`, `.gradle/`, `.m2/`)  
❌ Build output (`target/`, `dist/`, `build/`)  
❌ IDE settings (`.idea/`, `.settings/`)  
❌ Environment files (`.env*`, `secrets/`)  
❌ Certificates & keys (`*.pem`, `*.key`)  
❌ Logs (`logs/`, `*.log`)  
❌ Test coverage (`coverage/`, `jacoco-report/`)  
❌ OS files (`.DS_Store`, `Thumbs.db`)

## Usage Tips

### Adding to Git After Gitignore Change

```bash
# If you've committed files that should be ignored:
git rm --cached filename
git commit -m "Remove tracked files that should be ignored"

# Or for entire directory:
git rm --cached -r directory/
git commit -m "Remove tracked directory that should be ignored"
```

### Checking What Will Be Ignored

```bash
# Test which files would be ignored
git check-ignore -v filename

# See all ignored files
git status --porcelain --ignored
```

### Local Gitignore (Not Committed)

```bash
# For truly local patterns (not shared), use .git/info/exclude instead
echo "*.local" >> .git/info/exclude
```

### Unignoring Files (If Needed)

```bash
# Force add an ignored file
git add -f filename

# Or add exception to .gitignore
echo "!special-file.log" >> .gitignore
```

## Security Checklist

✅ `.env` files ignored (never commit secrets)  
✅ Certificate files ignored (`*.pem`, `*.key`)  
✅ Private keys ignored  
✅ Database credentials not in source  
✅ JWT secrets not in source (use environment variables)  
✅ `secrets/` directory for any stray secrets

## Performance Impact

- **Repo Size**: Reduced by excluding `node_modules/` (~500MB+), `target/` (~200MB+), etc.
- **Clone Speed**: Faster clones due to smaller repository
- **Commit Speed**: Faster commits with fewer tracked files
- **Push/Pull**: Reduced bandwidth usage
